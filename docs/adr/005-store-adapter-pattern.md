# ADR-005 서점별 어댑터 패턴을 쓴다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락

서점 페이지 구조는 예고 없이 바뀌고, 서점은 계속 늘어날 수 있다.

## 결정

`StoreAdapter` 인터페이스를 서점마다 `@Component`로 구현하고, 서비스는 `List<StoreAdapter>`를 주입받아 병렬 실행한다. 가져오기와 파싱을 분리해 파서는 저장해 둔 HTML로 테스트한다.

## 대안

- 서점 분기를 한 클래스에서 `if/switch`로 처리

## 결과

서점 추가는 클래스 하나 추가로 끝난다. 한 서점 장애가 다른 서점에 번지지 않는다.

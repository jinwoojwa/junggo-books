# ADR-002 백엔드는 Spring Boot 단일 애플리케이션으로 둔다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락

초안은 Next.js API 라우트 + 별도 수집 서버의 두 서버 구조였다. 1인 개발자는 Java·Spring에 익숙하고, 국내 백엔드 포트폴리오로서의 가치도 고려했다.

## 결정

프론트는 화면만 맡고, 도서 API 호출·서점 어댑터·캐시·DB는 Spring Boot 앱 하나가 맡는다.

## 대안

- Next.js 풀스택 + 수집 서버 분리
- 수집 전용 마이크로서비스

## 결과

배포·모니터링 대상이 하나로 줄었다. VM 한 대에서 Docker Compose로 운영한다 (ADR-010). JVM 메모리를 고려해 힙 크기를 컨테이너 메모리에 맞춘다. 수집 부하가 커지면 어댑터 모듈만 별도 서비스로 분리할 수 있게 패키지를 나눈다.

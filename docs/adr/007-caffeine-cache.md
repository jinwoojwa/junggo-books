# ADR-007 캐시는 Caffeine으로 시작하고 Redis는 보류한다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락

같은 책 반복 조회를 막아야 하지만, 서버는 VM 한 대이고 트래픽도 작다.

## 결정

Spring Cache + Caffeine(인메모리)을 쓴다. 키는 `{isbn13}:{store}`, 정상 결과 3시간·실패와 빈 결과 10분.

## 대안

- Redis: 서버 여러 대·재시작 후 유지에 유리하지만 운영 대상이 늘어난다.

## 결과

재배포하면 캐시가 비워진다. 서버를 여러 대로 늘리거나 캐시 적중률이 중요해지면 Redis로 바꾼다. Spring Cache 추상화 덕분에 교체 비용은 작다.

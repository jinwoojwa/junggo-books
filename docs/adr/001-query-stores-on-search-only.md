# ADR-001 서점 데이터는 검색 시점에만 조회한다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락

가격 비교 서비스는 보통 판매처 데이터를 미리 대량 수집해 둔다. 하지만 국내 판례에는 타인 웹사이트 정보를 반복적·체계적으로 복제하는 행위를 데이터베이스제작자 권리 침해로 본 사례가 있다.

## 결정

사용자가 검색한 책 한 권의 가격·링크만 그 시점에 조회하고, 결과는 짧게 캐시한 뒤 버린다.

## 대안

- 주기적 전체 수집: 응답은 빠르지만 법적·운영 부담이 크다.
- 서점 공식 API: 현재 이용할 수 없다.

## 결과

첫 검색은 느리다(최대 약 5초). 대신 저장 데이터가 적고 서점 요청도 수요만큼만 발생한다. 최저가 추이는 책·날짜·서점별 최저가 한 줄만 쌓아 대응한다.

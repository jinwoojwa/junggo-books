# ADR-008 백엔드는 GCP Cloud Run(최소 0·최대 1)에 배포한다

- 상태: 대체됨 → [ADR-010](010-single-vm-docker-compose.md)
- 날짜: 2026-10-29

## 맥락

1인 프로젝트이고 데모 단계라 트래픽이 적고 들쭉날쭉하다. GCP를 쓰기로 했고, 당시 월 예산은 2만 원이었다.

## 결정

Spring Boot 컨테이너를 서울 리전 Cloud Run에 배포한다. 최소 인스턴스 0으로 유휴 비용을 없애고, 최대 인스턴스 1로 Caffeine 캐시와 서점별 요청 간격 제한이 한 인스턴스에서 일관되게 동작하게 한다. 주기 작업은 Cloud Scheduler가 내부 엔드포인트를 호출한다.

## 대안

- Compute Engine VM: 상시 비용, 서버 관리 필요
- GKE: 과함
- 최소 인스턴스 1: 콜드 스타트 없음, 상시 비용
- 최대 인스턴스 여러 개 + Memorystore: 비용·복잡도 증가

## 결과

첫 요청은 콜드 스타트로 몇 초 느리고, 인스턴스가 내려가면 캐시가 비워진다. 이 점과 고정되지 않는 외부 IP 때문에 ADR-010으로 대체했다.

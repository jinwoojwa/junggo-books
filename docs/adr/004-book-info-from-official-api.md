# ADR-004 책 정보는 공식 도서 API에서 받는다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락

제목·저자·표지까지 서점에서 가져오면 수집 범위가 넓어지고 서점 콘텐츠를 복제하게 된다.

## 결정

국립중앙도서관 서지 API를 사용한다. 서점에서는 가격·배송비·상태·링크만 가져온다. 책 정보는 사용자가 가격 비교 화면에서 연 책만 DB에 저장하고, 30일이 지나면 갱신한다.

## 대안

- 서점 페이지에서 메타데이터까지 추출

## 결과

외부 도서 API 장애 시 검색이 멈춘다. book 테이블 저장과 검색 결과 캐시로 영향을 줄인다.
